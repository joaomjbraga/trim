Ativando o TRIM no Linux

Um guia rápido para ativar, verificar e automatizar o TRIM — a rotina que mantém seu SSD rápido e saudável ao longo do tempo.

💡 O que é TRIM? É o comando que avisa o SSD quais blocos de dados apagados podem ser reaproveitados. Sem ele, o disco acumula blocos "sujos" e as gravações ficam progressivamente mais lentas.

1 Ativar o timer do fstrim

systemd

A maioria das distros já vem com um serviço agendado para isso. Basta habilitá-lo:

terminal 
# habilita e inicia o timer agora mesmo
sudo systemctl enable fstrim.timer --now

2 Verificar se o timer está ativo

systemd

Confirme que o agendamento foi registrado corretamente:

terminal 
systemctl status fstrim.timer
✅ Se aparecer active (waiting) na saída, está tudo certo: o timer está agendado e vai rodar sozinho.

3 Forçar uma execução manual

Quer testar agora, sem esperar o próximo ciclo agendado? Rode o TRIM direto na partição raiz:

terminal 
sudo fstrim /

+ Criar um preset personalizado

Para garantir que o fstrim.timer continue ativo mesmo após reinstalações ou em sistemas provisionados automaticamente, crie um preset dedicado:

terminal 
# 1. cria o diretório de presets, se não existir
sudo mkdir -p /etc/systemd/system-preset/

# 2. cria/edita o arquivo de preset
sudo nano /etc/systemd/system-preset/90-custom.preset

# 3. adiciona esta linha dentro do arquivo
enable fstrim.timer
📌 Por que isso é útil: presets do systemd definem o estado padrão dos serviços do sistema. Com essa regra salva, qualquer preset-all futuro mantém o TRIM habilitado automaticamente.

Depois de salvar o arquivo, aplique a mudança:

terminal 
sudo systemctl preset-all

4 Checagem final

Rode o status mais uma vez para confirmar que tudo ficou no lugar:

terminal 
systemctl status fstrim.timer
✅ active (waiting) na tela significa que o seu SSD vai receber TRIM automaticamente — sem você precisar pensar nisso de novo.
